[심화] ViT와 ResNet을 같은 learning rate로 비교해도 공정할까?

[심화] ViT와 ResNet을 같은 learning rate로 비교해도 공정할까?
  • 질문: 구조가 다른 두 모델을 같은 learning rate로 학습시켜 비교하면, 그 비교에서 내린 결론을 믿을 수 있을까?
  • 출발한 논문: ViT 리뷰 — 4.1절(학습 설정), 4.3절(데이터 규모 실험), 부록 B.1과 D.3 · ResNet (비교 대상)
  • 실험 코드: GitHub · 학습은 리뷰 노트북에서 VIT_LR=1e-3(같은 lr)로 실행: Colab
  • 분류: 학습-방법

질문

ViT 리뷰의 재현 실험을 처음 돌렸을 때는 ViT와 ResNet-18을 같은 learning rate(1e-3)로 학습시켰다. “같은 조건에서 비교해야 공정하다”고 생각했기 때문이다. 논문 4.1절도 언뜻 그렇게 읽힌다. ResNet을 포함한 모든 모델을 같은 optimizer(Adam, \(\beta_2 = 0.999\)), 같은 batch(4096), 같은 weight decay(0.1)로 학습했다고 쓴다.

그런데 부록 B.1의 Table 3을 보면 learning rate는 모델마다 다르다. ViT-B는 \(8 \times 10^{-4}\), ViT-L/16은 \(4 \times 10^{-4}\), ViT-H/14는 \(3 \times 10^{-4}\), ResNet은 \(10^{-3}\)이다. 부록 D.3에는 learning rate 때문에 결론이 뒤집힐 뻔한 일도 적혀 있다. [class] 토큰 대신 평균 pooling을 쓴 첫 시도는 아주 나빴는데, 원인은 pooling 방식이 아니라 learning rate가 맞지 않았던 것이었다.

그렇다면 learning rate를 하나로 통일한 비교는 공정한 비교일까, 한쪽에 불리한 비교일까? 그리고 그 차이가 논문의 결론을 재현하느냐 마느냐를 바꿀 만큼 클까?

논리적 고찰

learning rate는 모델마다 “맞는 크기”가 다르다

learning rate가 얼마나 커도 되는지는 loss 표면이 얼마나 가파른지(곡률)에 달려 있다. 가장 단순한 경우로, 곡률이 \(a\)인 2차 함수 \(f(x) = \tfrac{a}{2}x^2\)에 경사하강법을 쓰면 다음과 같다.

\[x_{t+1} = x_t - \eta \, f'(x_t) = (1 - \eta a)\, x_t\]

\(\vert 1 - \eta a \vert < 1\), 즉 \(\eta < 2/a\)여야 수렴한다. 곡률이 큰 문제일수록 작은 learning rate가 필요하다. 그러면 곡률이 다른 두 문제에 같은 learning rate를 쓰면 어떻게 될까?

작은 문제로 확인하기

곡률이 1인 문제와 10인 문제에 같은 learning rate로 5 step씩 경사하강법을 돌렸다. 시작점은 \(x_0 = 1\), 최솟값은 0이다.

learning rate완만한 문제 (\(a\)=1)가파른 문제 (\(a\)=10)
0.051 → 0.95 → 0.90 → 0.86 → 0.81 → 0.771 → 0.50 → 0.25 → 0.13 → 0.06 → 0.03
0.151 → 0.85 → 0.72 → 0.61 → 0.52 → 0.441 → −0.50 → 0.25 → −0.13 → 0.06 → −0.03
0.251 → 0.75 → 0.56 → 0.42 → 0.32 → 0.241 → −1.50 → 2.25 → −3.38 → 5.06 → −7.59

같은 learning rate가 완만한 문제에서는 너무 작고(왼쪽, 0.05는 5 step 후에도 0.77), 가파른 문제에서는 너무 크다(오른쪽, 0.25는 발산).

완만한 문제에는 0.25가 가장 좋지만, 가파른 문제에서는 0.25가 발산한다. 가파른 문제에 안전한 0.05는 완만한 문제에서 거의 진전이 없다. 두 문제 모두에게 좋은 learning rate는 없다. 하나의 값으로 통일하면 적어도 한쪽은 손해를 본다.

ViT와 ResNet의 차이

신경망에서는 곡률이 이렇게 깔끔하게 정의되지 않지만, 두 모델이 learning rate에 다르게 반응할 이유는 충분하다.

  • ResNet에는 BatchNorm이 있다. BatchNorm 논문은 BatchNorm이 훨씬 큰 learning rate를 쓸 수 있게 해준다고 보고했다. CNN 학습 recipe가 큰 learning rate를 쓰는 이유 중 하나다.
  • ViT에는 softmax attention이 있다. 큰 update로 query·key 가중치가 커지면 attention logit이 커지고 softmax가 한쪽으로 쏠린다. 심화: √d_k로 나누지 않으면?에서 본 것처럼, 쏠린 softmax는 gradient를 잘 흘리지 않는다. Transformer 학습이 불안정해질 때 attention이 한 토큰에 몰리는 현상(attention entropy collapse)이 나타난다는 보고도 있다(Zhai et al., 2023).

가설

ViT가 ResNet보다 큰 learning rate에 약하다면, 둘 다 1e-3으로 학습시킬 때 ViT만 손해를 본다. 그 손해는 데이터가 많은 설정에서 더 클 것이다. 데이터가 적으면 작은 learning rate로도 금방 외워 버리지만, 데이터가 많으면 학습이 제대로 진행되어야 정확도가 오르기 때문이다. 그렇다면 같은 learning rate로는 “데이터가 늘수록 ViT가 ResNet을 따라잡는다”는 논문의 경향이 가려질 것이다.

실험 설계

리뷰 글의 CIFAR-10 실험(ViT 14.2M vs ResNet-18 11.2M, 7,800 step)을 learning rate만 바꿔 두 번 돌렸다.

결과

learning rate 하나로 18%p가 움직인다

ViT, CIFAR-10 100%. learning rate를 1e-3에서 2.5e-4로 낮추자 train 정확도가 65%에서 94%로, test 정확도가 63.5%에서 81.5%로 올랐다.

1e-3 (ResNet과 같음)65.1%63.5%

1e-3에서 ViT는 학습 데이터조차 65%밖에 못 맞췄다. 과적합이 아니라 학습 자체가 제대로 되지 않은 과소적합이다. 이 실행의 attention 거리를 분석할 때는, 일부 head에서 patch끼리의 attention 합이 수치적으로 0이 되어 계산이 NaN으로 깨졌다. 그 head들이 attention을 거의 전부 [class] 토큰에 몰아줬다는 뜻이다. 가설에서 예상한 softmax 쏠림과 같은 방향이다. (lr 2.5e-4 실행에서는 [class] 토큰에 간 attention이 head마다 0.6~4.0%였다.)

결론이 뒤집힌다

왼쪽: ViT 정확도(주황)와 ResNet 정확도(파랑). 오른쪽: 두 모델의 차이. 같은 learning rate(회색 점선)에서는 데이터를 10배 늘려도 차이가 4.4%p밖에 줄지 않지만, 모델별 learning rate(파란 실선)에서는 16.9%p 줄어든다.

학습 이미지ResNet-18ViT (같은 lr 1e-3)차이ViT (lr 2.5e-4)차이
5,00082.9%48.2%34.7%p53.7%29.2%p

같은 learning rate의 결과만 봤다면 이렇게 결론 내렸을 것이다. “데이터를 10배 늘려도 ViT는 ResNet과의 차이를 거의 줄이지 못한다(34.7 → 30.3%p). 데이터 규모가 ViT를 돕는다는 논문의 주장은 작은 규모에서는 보이지 않는다.” 모델별 learning rate에서는 정반대다. 차이가 29.2 → 12.3%p로 크게 줄어, 논문 Figure 3·4와 같은 경향이 나타난다.

가설대로 손해는 데이터가 많은 쪽에서 더 컸다. 5,000장에서는 learning rate를 바꿔도 ViT가 5.5%p 오르지만, 50,000장에서는 18.0%p 오른다.

위치 임베딩 ablation도 영향을 받았다. 위치 임베딩을 뺐을 때의 하락이 같은 learning rate에서는 4.0%p(63.5% → 59.6%), 모델별 learning rate에서는 9.1%p(81.5% → 72.4%)였다. 모델이 제대로 학습되지 않으면 구성 요소의 기여도도 작게 측정된다.

결론과 한계

구조가 다른 모델을 같은 learning rate로 비교하는 것은 공정하지 않았고, 그 불공정함이 결론을 바꿀 만큼 컸다. 같은 learning rate는 “같은 조건”처럼 보이지만, 실제로는 그 값에 더 잘 맞는 모델(여기서는 ResNet)에게 유리한 조건이다. 논문이 모델마다 learning rate를 따로 정하고(부록 Table 3), [class] 토큰 비교에서도 learning rate를 맞춘 뒤에야 결론을 낸 것(부록 D.3)은 같은 이유로 보인다. 구조를 비교하는 실험에서는 모델마다 최소한 작은 learning rate 탐색을 해야 하고, 그것이 어렵다면 각 모델 계열의 검증된 recipe를 따라야 한다.

이 실험의 한계는 다음과 같다.

  • ResNet의 learning rate는 탐색하지 않았다. 1e-3이 ResNet에게도 최적이라는 보장은 없다. ResNet도 더 좋아질 수 있으므로, 여기서 측정한 “차이”는 ViT 쪽만 조정한 결과다.
  • ViT도 세 값만 봤다. 2.5e-4보다 더 작은 값이 더 좋을 수도 있다.
  • seed가 1개다. 18%p나 16.9%p 같은 큰 차이는 seed 편차로 설명되기 어렵지만, 위치 임베딩의 1D와 2D 차이(0.1~0.2%p) 같은 작은 차이는 판단할 수 없다.
  • step 수를 고정했다. learning rate를 낮추면 같은 step에서 덜 움직이므로, 학습 길이와 learning rate가 함께 얽혀 있다. 더 오래 학습하면 1e-3도 따라잡을지는 확인하지 않았다.
